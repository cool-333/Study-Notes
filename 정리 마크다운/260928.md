## 콜백

콜백 : 순서를 지키려면 중첩되어야 한다.

```html
<button id="callback">콜백 실행</button>
<p id="callResult"></p>
```

```js
document.querySelector("#callback").addEventListener("click", () => {
  const result = document.querySelector("#callResult");
  result.textContent = "콜백 시작!";
  setTimeout(() => {
    result.textContent = "1초 후 실행";
    setTimeout(() => {
      result.textContent = "2초 후 실행";
      setTimeout(() => {
        result.textContent = "3초 후 실행";
      }, 1000);
    }, 1000);
  }, 1000);
});
```

## async / await

then 없이 위에서 아래로 실행. async 함수 안에서만 await 사용 가능

```html
<p>Promise를 "동기적 코드처럼" 작성</p>
<button id="async">async/await 실행</button>
<p id="asyAwaResult"></p>
```

```js
document.querySelector("#async").addEventListener("click", async () => {
  const delay = (message) => {
    return new Promise((resolve) => {
      setTimeout(() => resolve(message), 1000);
    });
  };
  const result = document.querySelector("#asyAwaResult");
  result.textContent = "async 시작!";
  // await - Promise가 끝날 때까지 기다리라고 명령하는 것과 같다
  const response = await delay("1초 후 실행");
  result.textContent = response;
  const response2 = await delay("2초 후 실행");
  result.textContent = response2;
});
```

## fetch

서버에서 데이터 하나 가져오는 것. 자바스크립트에서 서버로 요청을 보내고 응답을 받을 수 있도록 해주는 함수.

```html
<button id="fetch">드라마 정보 가져오기</button>
<div id="fetchResult"></div>

<button id="fetchList">회원 목록 가져오기</button>
<ul id="userList"></ul>
```

```js
document.querySelector("#fetch").addEventListener("click", async () => {
  const result = document.querySelector("#fetchResult");
  const response = await fetch("https://api.tvmaze.com/shows/1");
  const data = await response.json();
  console.log(data.image.medium);
  result.innerHTML = `<img src="${data.image.medium}" />
  <h3>${data.name}</h3>
  <p>${data.summary}</p>`;
});

document.querySelector("#fetchList").addEventListener("click", async () => {
  const resultList = document.querySelector("#userList");
  const response = await fetch("https://jsonplaceholder.typicode.com/users");
  const data = await response.json();
  data.forEach((user) => {
    userList.innerHTML += `<li>
    <h3>${user.name}</h3>
    <p>${user.email}</p>
    <p>${user.address.city}</p>
    </li>`;
  });
});
```

## Chart.js

외부 라이브러리 사용법 -> API 문서의 Getting Started, Installation 등 -> CDN -> 예제 그대로 복사 -> 내 데이터에 붙여넣기

```html
<div>
  <canvas id="myChart"></canvas>
</div>
```

```js
const ctx = document.getElementById("myChart");

const spending = [
  { category: "식비", amount: 320000 },
  { category: "교통", amount: 85000 },
  { category: "카페", amount: 64000 },
];

new Chart(ctx, {
  type: "bar", // bar, doughnut, line, pie, ...
  data: {
    labels: spending.map((item) => item.category),
    datasets: [
      {
        label: "이번 달 지출(원)",
        data: spending.map((item) => item.amount),
        borderWidth: 1,
      },
    ],
  },
  options: {
    scales: {
      y: {
        beginAtZero: true,
      },
    },
  },
});
```
