### 08. grid

#### display: grid

2단 레이아웃 스타일

#### grid-template-columns / rows

```html
<div class="grid template">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

```css
.grid {
  display: grid;
  backgrond: #eee;
  gap: 10px; /* grid의 경우 row-gap, column-gap 이 있다. */
  padding: 10px;
}

.item {
  background: #43aaff;
  color: white;
  padding: 12px 16px;
  /* 텍스트를 정중앙으로 옮길 때 flex 사용.
    -> item이 부모고 그 안의 콘텐츠가 자식이 되므로, 하단처럼 사용 가능하다. */
  display: flex;
  justify-content: center;
  align-items: center;
}

/* grid-template-columns, rows */
.template {
  /* 칸의 열 너비를 정한다. 열을 n개 만든다는 의미 */
  grid-template-columns: 100px 200px 100px;
  /* 칸의 행 높이를 정한다. 행을 n개 만든다는 의미*/
  grid-template-rows: 50px 100px;

  /* n번 반복하여 npx로 맞춘다. */
  grid-template-columns: repeat(2, 150px);
  grid-template-rows: repeat(2, 80px);
}
```

#### grid-column / grid-row

```html
<div class="grid cr">
  <div class="item column">1</div>
  <div class="item row">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

```css
/* grid-column, row -> fr(fraction-비율) = 남는 공간을 나누는 비율 단위이다. */
.cr {
  /* 균등하게 분배하므로 repeat(n, npx)과 동일하다. */
  grid-template-columns: 1fr 1fr 1fr;
}

.cr .column {
  grid-column: span 3; /* 1번 선 ~ 4번 선까지 가로로 차지. 검사탭(F12)으로 확인 가능. 동그란 grid 버튼 눌러야 숫자가 보인다.
  -> 1 / 4 = 3칸을 차지 = span 3. */
}

.cr .row {
  grid-row: span 2; /* 2번 선 ~ 4번 선까지 세로로 차지. 상동.
  -> 2 / 4 = 2칸을 차지 = span 2. */
}
```

#### grid-template-areas

레이아웃에 이름을 붙여 사용한다.

```html
<div class="grid area">
  <div class="item header">header</div>
  <div class="item nav">nav</div>
  <div class="item main">main</div>
  <div class="item section">section</div>
  <div class="item footer">footer</div>
</div>
```

```css
.area {
  grid-template-columns: 1fr 2fr;
  grid-template-areas:
    "header header"
    "nav main"
    "nav section"
    "footer footer";
}
.header {
  grid-area: header;
}
.nav {
  grid-area: nav;
}
.main {
  grid-area: main;
}
.section {
  grdi-area: section;
}
.footer {
  grid-area: footer;
}
```

#### auto-fit vs auto-fill

```html
<div class="grid fit">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>

<div class="grid fill">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

```css
.fit {
  /* 채울 아이템이 부족하면 아이템들이 공간을 나눠 가진다. */
  grid-template-columns: repeat(auto-fit, minmax(120px, 1fr));
}

.fill {
  /* 채울 아이템이 부족해도 빈 공간을 그대로 유지한다. */
  grid-template-columns: repeat(auto-fill, minmax(120px, 1fr));
}
```

#### align-items vs justify-items

```html
<div class="grid items">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>

<div class="grid content">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

```css
.items,
.content {
  grid-template-columns: repeat(3, 100px);
  grid-template-rows: repeat(2, 80px);
}
.items {
  /* items는 각 칸 "안"에서 아이템의 위치를 조정한다. */
  align-items: end;
  justify-items: center;
}
.content {
  /* 그리드 자체를 어디에 배치할지를 조정한다. */
  height: 300px;
  align-content: end;
  justify-content: center;
}
```

### 09. 인터랙션

#### Transition

```html
<div class="container">
  <div class="box transition">Hover</div>
</div>
```

```css
.container {
  display: flex;
  gap: 10px;
  border: 1px solid #eee;
}
.box {
  width: 140px;
  height: 140px;
  background: #333;
  color: white;
  display: flex;
  align-items: center;
  justify-content: center;
  border-radius: 10px;
  font-size: 1.2rem;
}

.transition {
  transition: all 3s linear;
  /* 적용 대상 property, 지속 시간 duration 변화 속도 timing-function (linear=일정하게) */
}
.transition:hover {
  background: #ffa114;
  cursor: pointer; /* 마우스 포인터를 손 모양으로 표시한다. */
}
```

#### Transfrom

요소를 확대/회전/이동/기울이기를 할 수 있다.

```html
<div class="container">
  <div class="box scale">Scale</div>
  <div class="box rotate">Rotate</div>
  <div class="box translate">Translate</div>
  <div class="box skew">Skew</div>
</div>
```

```css
.scale {
  background-color: indianred;
}
.scale:hover {
  transform: scale(1.2); /* 확대 */
}

.rotate {
  background-color: indigo;
}
.rotate:hover {
  transform: rotate(30deg); /* 회전 */
}

.translate {
  background-color: cadetblue;
}
.translate:hover {
  transform: translate(20px, 50px);
}

.skew:hover {
  /* x축 값 기울기, y축 값 기울기 --> skew(X, Y) = (좌우 방향 비틀기, 위아래 방향 비틀기) */
  transform: skew(10deg, -30deg);
}
```

#### Animation

@keyframs 태그로 여러 단계를 지정한다. 애니메이션 이름 지정 & 프레임에 효과 지정 후, 효과 적용까지 해야 정상적으로 작동한다.

```html
<div class="container">
  <div class="box ani-once">1회</div>
  <div class="box ani-loop">무한</div>
  <div class="box ani-pause">Pause</div>
</div>
```

```css
@keyframes bounce {
  0% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-50px);
  }
  100% {
    transform: translateY(0);
  }
}

.ani-once {
  /* name: 애니메이션 이름
    duration: 지속 시간
    timing-function: 속도 변화
    iteration-count: 반복 횟수 */
  animation: bounce 2s linear 1;
}
.ani-loop {
  background-color: navy;
  animation: bounce 2s linear infinite; /* 무한 반복 */
}
.ani-pause {
  background: salmon;
  animation: bounce 2s linear infinite;
}
.ani-pause:hover {
  animation-play-state: paused;
}
```

#### 10. Media Query

미디어 쿼리 (Media Query)는 화면 크기에 따라 스타일을 바꾼다.

```css
body {
  background: lightblue;
  color: red;
}

/* [데스크탑 기준] max-width 최대 너비. 이 너비보다 좁아지면 효과가 덮어씌워진다. */
@media (max-width: 1000px) {
  body {
    color: blue;
  }
}
@media (max-width: 700px) {
  /* 700px 이하 */
  body {
    color: orange;
  }
}
/* [모바일 기준] min-width: 이 너비보다 넓어지면 효과가 덮어씌워진다. */
@media (min-width: 700px) {
  /* 최소 700px 이상 */
  body {
    background-color: lightseagreen;
  }
}
@media (min-width: 1000px) {
  body {
    background-color: coral;
  }
}
```

#### aspect-ratio

높이를 직접 계산하지 않아도 가로세로 비율을 고정한다.<br>
&nbsp;&nbsp;&nbsp;-> 이미지나 카드 썸네일에 유용하다.

```html
<div class="ratio-grid">
  <div class="ratio-card">16:9</div>
  <div class="ratio-card">4:3</div>
  <div class="ratio-card">1:1</div>
</div>
```

```css
.ratio-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 10px;
}
.ratio-card {
  background: #111;
  color: white;
  display: flex;
  justify-content: center;
  align-items: center;
  font-weight: bold;
}
.ratio-card:first-child {
  aspect-ratio: 16/9; /* 영상 썸네일 */
}
.ratio-card:nth-child(2) {
  aspect-ratio: 4/3;
}
.ratio-card:last-child {
  aspect-ratio: 1/1; /* 프로필 이미지 */
}
```
