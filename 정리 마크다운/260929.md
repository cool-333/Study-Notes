## 정규표현식(Regular Expression)

문자열에서 특정 패턴을 찾거나, 대체하거나, 나누는 도구

```html
body 바로 위에
<script src="./10-form-storage.js"></script>
```

```html
<ul>
  <li>^ 시작, $ 끝 : 둘 다 쓰면 처음부터 끝까지</li>
  <li>\d 숫자, \w 영문, 숫자 , _, \s 공백 : 각 대문자는 해당하는 값들 제외</li>
  <li>
    . 임의의 한 문자, * 앞 문자가 0회 이상, + 앞 문자가 1회 이상, ? 앞 문자가
    0~1회
  </li>
  <li>
    [] 문자셋 : a-z 알파벳 소문자, A-Z 알파벳 대문자, 0-9 숫자, 가-힣 한글
  </li>
  <li>{m} m회, {m,n} : m부터 n회 반복</li>
</ul>
```

```js
// 정규표현식 - /패턴/.test.(문자열) -> true / false
// replace, split 등 문자열 함수와 사용 가능
console.log(`^ 시작 : ${/^H/.test("Hello")}`); // H로 시작
console.log(`$ 끝 : ${/o$/.test("Hello")}`); // o로 끝

console.log(`\d 숫자 : ${/\d\d$/.test("12")}`); // 숫자 (0~9)
console.log(`\w 영문,숫자,_ : ${/^\w$/.test("_")}`); // _
console.log(`. 한 문자 : ${/H.llo/.test("Hello")}`); // H□llo

console.log(`* 0회 이상 : ${/abc*d/.test("abcccccccccd")}`); // * 앞의 문자인 c가 0회 이상이면 true
console.log(`+ 1회 이상 : ${/abc+d/.test("abcccccccccd")}`); // * 앞의 문자인 c가 1회 이상이면 true
console.log(`? 0~1회 : ${/abc?d/.test("abcccccccccd")}`); // * 앞의 문자인 c가 0~1회이면 true -> false

console.log(`[A-Z] 문자셋 : ${/^[A-Za-z가-힣]+$/.test("a")}`); // 대문자 및 소문자, 한글 상관없이 -> true

console.log(`{2,4} 반복 : ${/^a{2,4}$/.test("aa")}`);

console.log("사과, 바나나, 오렌지".split(/,/)); // -> ['사과', ' 바나나', ' 오렌지']
console.log("010-1234-5678".replace(/-/g, "")); // g = global의 약자(전부)
```

## 입력할 때마다 검사

```html
<input type="text" id="phone" placeholder="010-1234-5678" />
<span id="phoneCheck"></span>
```

```js
입력할 때마다 검사 -> 회원가입
const phoneCheck = document.querySelector("#phoneCheck");
document.querySelector("#phone").addEventListener("input", (e) => {
  if (/^010-\d{4}-[0-9]{4}$/.test(e.target.value)) {
    phoneCheck.textContent = "OK!";
    phoneCheck.style.color = "green";
  } else {
    phoneCheck.textContent = "형식이 맞지 않아요 ㅠㅠ";
    phoneCheck.style.color = "red";
  }
});
```

## Web Storage - 브라우저에 저장

```html
- sessionStorage 그 탭을 닫으면 사라짐<br />
- localStorage 브라우저를 껐다 켜도 남음 (직접 지우기 전까지)
<button id="saveSession">sessionStorage 저장</button>
<button id="saveLocal">localStorage 저장</button>
<button id="readLocal">읽기</button>
<button id="removeLocal">삭제</button>
<button id="clear">전부 삭제</button>
<p id="result"></p>
```

```js
Web Storage : set Item(키,값) 저장 | getItem(키) 가져오기 | removeItem(키) 삭제 | clear() 전부 삭제
document.querySelector("#saveSession").addEventListener("click", () => {
  sessionStorage.setItem("visit", "오늘 처음 방문");
});
document.querySelector("#saveLocal").addEventListener("click", () => {
  // JSON.stringify -> 객체 to 문자
  localStorage.setItem("profile", JSON.stringify({ name: "테스트", age: 10 }));
});
const result = document.querySelector("#result");
document.querySelector("#readLocal").addEventListener("click", () => {
  const profile = JSON.parse(localStorage.getItem("profile"));
  result.textContent = profile.name;
});
document.querySelector("#removeLocal").addEventListener("click", () => {
  localStorage.removeItem("profile");
});
document.querySelector("#clear").addEventListener("click", () => {
  localStorage.clear();
});
```
