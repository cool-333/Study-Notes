- div 코드는 콘텐츠가 있거나 width, height 값이 있지 않는 한 표시되지 않는다.
  - div 코드를 html에 작성하고, css 파일에서 height: 100vh; 로 사진을 전체 높이로 적용할 수 있다.
  - 미작성된 width는 div 코드에서는 기본적으로 전체 가로값으로 적용된다.

- css에 전체 선택자(\*)로 margin값 0, padding값 0, box-sizing: border-box를 넣고 시작하기도 한다.
  - 단, 이 경우 행간을 일일이 지정해야 한다.
  - border-box는 내부 콘텐츠에서 margin을 줬을 때 밀림 현상을 방지하기 위함이다.

- text-align: center;는 텍스트와 이미지만 가운데로 정렬시킨다.

- height: 100vh;와 backgrouknd-attachment: fixed;는 비슷한 효과를 낸다.

- margin: auto;는 해당 요소가 가로 크기를 가지면 균등하게 여백을 지정한다.
  - margin은 밀리는 효과가 있어, 배경을 넣은 후 내부 콘텐츠에서 마진을 주면 배경이 밀린다. (이 경우 상술했듯 \*에서 box-sizing: border-box 이용한다.)

- img 태그로는 html에서 이미지 태그 작성 : 데이터가 자꾸 바뀔 때
- background 속성으로는 css에서 이미지 -> 데이터가 바뀌지 않는 경우

- 앞으로 해야 할 일을 주석으로 적어놓고 진행하는 것도 좋다.

## 07. flex

### display:flex -> 부모에 한 줄 입력되어 있어야 한다.

```html
<div class="container">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
/* display: flex를 반드시 부모에게 작성해야 적용된다. */
.container {
  background-color: #eef1f5;
  display: flex;
}

.item {
  padding: 5px 5px;
  border: 2px solid;
  background-color: white;
}
```

### flex-direction 주축 방향

```html
<div class="container column">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
/* flex-direction : row(기본값), row-reverse, column, column-reerse
                    row -> 행(가로) / column ->열(세로) */
.column {
  flex-direction: column;
}
```

### justify-content(주축) / align-tiems(교차축)

- 부모한테 justify-content, align-items 적용할 것
  - justify-content : start(기본값), end, center, space-between(양끝), space-around, space-evenly
  - align-items : stretch(기본값), start, end, center, baseline

```html
<div class="container align">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
.align {
  height: 100px;
  flex-direction: row;
  /* flex-direction에 따라 주축과 교차축이 바뀐다. */
  justify-content: space-between; /* 주축 */
  align-items: center; /* 교차축 */
}
```

### flex-wrap 줄바꿈

부모한테 flex-wrap : nowrap(기본값 - 찌그러트림), wrap

```html
<div class="container wrap">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
  <div class="item">4</div>
  <div class="item">5</div>
  <div class="item">6</div>
</div>
```

```css
.wrap {
  height: 200px;
  flex-wrap: wrap;
  justify-content: space-between;
  /* align-content는 줄바꿈 시 사용, justify-content에서 사용하는 값들과 동일하다. */
  align-content: space-around;
}

.wrap .item {
  width: 150px;
}
```

### gap 아이템 사이 간격

부모한테 gap

```html
<div class="container gap">
  <div class="item">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
.gap {
  gap: 10px; /* margin과의 차이점 : 바깥쪽 여백은 생기지 않는다. */
}
```

## 여기부터는 자식한테한테 주는 속성들

### flex-grow 남는 공간 비율로 나눠 갖기

```html
<div class="container">
  <div class="item grow-1">1</div>
  <div class="item grow-2">2</div>
  <div class="item">3</div>
</div>
```

```css
.grow-1 {
  flex-grow: 2;
}
.grow-2 {
  flex-grow: 1;
}
```

### flex-shrink 공간이 부족할 시 비율로 줄이기

```html
<div class="container shrink">
  <div class="item shrink-0">1</div>
  <div class="item">2</div>
  <div class="item">3</div>
</div>
```

```css
.shrink .item {
  flex-basis: 300px; /* 아이템 주축 시작 크기 width와 유사 (함께 사용 시 width를 이긴다.) */
}
.shrink-0 {
  flex-shrink: 2; /* flex-shrink 값이 0이면 고정, 1 이상이면 커질수록 줄어드는 비율 UP */
}
```

### flex : grow shrink basis

```html
<div class="container">
  <div class="item flex-1">1</div>
  <div class="item flex-1">2</div>
  <div class="item flex-1">3</div>
</div>
```

```css
.flex-1 {
  flex: 1; /* = flex: 1 1 0; 아이템들을 균등하게 */
}

.flex {
  height: 300px;
}
```

### order / align-self

```html
<div class="container order-self">
  <div class="item">1</div>
  <div class="item self">2</div>
  <div class="item order">3</div>
</div>
```

```css
.order-self {
  height: 200px;
  align-items: center;
}
.order {
  order: -1;
  /* 기본값이 0, 작을수록 앞으로, 클수록 뒤로 간다. */
}
.self {
  align-self: end;
}
```
