### 05. 배경

#### background-color

background-color는 배경색 하나이다. (-color는 생략 가능)

```html
<h2>background-color</h2>
<div class="box bg-color"></div>
```

```css
.box {
  height: 200px;
}

.bg-color {
  background-color: blue;
}
```

#### background-image

background-image는 배경 이미지다.

```html
<h2>backgroound-image</h2>
<div class="box pic"></div>
```

```css
.pic {
  background-image: url(../01-html-css/assets/panda.png);
}
```

#### background-repeat:no-repeat + position:center

```html
<div class="box pic bg-norepeat"></div>
```

```css
/* background-repeat + position */
.bg-norepeat {
  background-color: #333;
  background-repeat: no-repeat;
  background-position: center;
}
```

#### background-size

- background-size -> cover 사용 多
  - cover : 사이즈의 비율을 유지하며 영역을 꽉 채운다. (넘치는 부분 잘림)
  - contain : 비율을 유지하면 사진이 다 보이게 표시한다. (빈 공간이 생김)

```html
<div class="box pic bg-cover"></div>
```

```css
.bg-cover {
  background-size: contain;
  background-position: center;
  background-repeat: no-repeat;
}
```

#### background-attachment:fixed

background-attachment: fixed 배경을 화면에 고정한다.

```html
<div class="box pic bg-fixed"></div>
```

```css
.bg-fixed {
  background-attachment: fixed;
}
```

#### gradient

gradient 색이 서서히 바뀌는 것이다. -> CSS에서는 이미지로 취급함에 주의!

```html
<div class="box bg-gradient"></div>
```

```css
.bg-gradient {
  /* linear-gradient (각도:degree, 처음 색상, 끝 색상 */
  background-image: linear-gradient(135deg, red, blue);
  /* radial-gradient (모양, 색깔1, 색깔2, 색깔3, ...) */
  background-image: radial-gradient(circle, red, blue, yellow);
}
```

#### 사진 + 투명 검정

background-image에서 ,(콤마)로 나열하는 방식이다.

```html
<div class="box bg-overlay"></div>
```

```css
.bg-overlay {
  background-image:
    linear-gradient(rgba(0, 0, 0, 0.45), rgba(0, 0, 0, 0.45)),
    url("../01-html/assets/panda.png");
}
```

#### blend-mode 색 + 사진 섞기

- background-blend-mode : background-color + background-image
  - color와 image를 같이 사용하면 image만 나타나므로, blend-mode까지 적용해야 한다.

```html
<div class="box bg-blend"></div>
```

```css
.bg-blend {
  background-color: rgb(0, 0, 0, 0.45);
  background-image: url(../01-html/assets/panda.png);
  background-blend-mode: overlay;
}
```

#### background 축약형

- background: color image repeat position / size 순서
  - 콜론으로 구분하지 않고 값만 넣는다.

```html
<div class="box bg"></div>
```

```css
.bg {
  background: #333 url(../01-html/assets/panda.png) no-repeat center / contain;
}
```

### 06. 박스모델    

#### width / height

```html
<h2>width / height</h2>
<div class="box w-fixed">px 단위는 고정 길이</div>
<div class="box w-percent">% 단위는 가변 길이</div>
```

```css
.box {
  background-color: azure;
  border: 1px solid;
  margin-bottom: 10px;
}

/* width 가로(너비), height 세로(높이) */
.w-fixed {
  width: 200px;
  height: 100px;
}

.w-percent {
  width: 50%;
  height: 100px; /* 부모의 값이 있어야 height의 %값이 계산된다. */
}
```

#### padding - 테두리와 내용 사이 (박스 안쪽 여백)

```html
<div class="box pad-all">padding: 20px</div>
<div class="box pad-parts">padding: 30px 20px 40px 10px</div>
```

```css
.pad-all {
  padding: 20px;
}

.pad-parts {
  /* top 위, right 오른쪽, bottom 아래, left 왼쪽 */
  padding-left: 10px;

  /* 값이 2개 : 상하 좌우ㅏ 순으로 적용. */
  padding: 30px 20px 40px 10px;

  /* 값이 3개 : 위 좌우 아래 순으로 적용. */
  padding: 30px 20px 40px;

  /* 값이 4개 : 위 오른쪽 아래 왼쪽 (시계방향) 순으로 적용. */
  padding: 30px 20px 40px 10px;
}
```

#### margin 요소와 요소 사이 (박스 바깥 여백)

```html
<div class="box mar-all">margin : 24px</div>
<!-- margin collapse(상쇄) : 두 박스 사이가 더해지는 게 아니라 큰 값 하나로 합쳐진다. -->
<div class="box mar-all" style="margin-top: 48px">margin : 24px</div>
<div class="box mar-auto">width:300px + margin: auto : 가운데</div>
```

```css
/* margin */
.mar-all {
  /* margin도 padding처럼 top, right, bottom, left이 존재하며,
    margin 값 개수에 따라 방향 4개 조절하는 규칙도 동일하다. */
  margin: 24px;
}

.mar-auto {
  width: 300px;
  /* margin: auto;는 좌우만 오토이다. */
  margin: auto;
}
```

#### border 테두리 : 두께 / 종류 (solid, dashed, dotted, ···) / 색

```html
<div class="bd-solid"></div>
<div class="bd-round"></div>
<div class="bd-circle"></div>
```

```css
.bd-solid {
  width: 90px;
  height: 90px;
  border: 3px solid red; /* solid 실선*/
}

.bd-round {
  width: 90px;
  height: 90px;
  border: 3px dashed green; /* dashed 점선 */
  border-radius: 10px; /* radius 모서리의 둥근 정도 */
}

.bd-circle {
  width: 90px;
  height: 90px;
  border: 3px dotted blue; /* dotted 점선 */
  border-radius: 50%; /* 사각형 -> 원. 50% 이상도 적용은 되나 더 줄어들지는 않는다. */
}
```

#### box-sizing:border-box

```html
<div class="box bs-content">content-box</div>
<div class="box bs-border">border-box</div>
```

```css
.bs-content,
.bs-border {
  width: 200px;
  height: 80px;
  padding: 20px;
  border: 5px solid aquamarine;
}

.bs-content {
  /* 기본값. width만 -> 실제 200 + 20*2 + 5*2 = 250 */
  box-sizing: content-box;
}

.bs-border {
  /* 테두리를 포함하여 안쪽까지가 기준. -> 실제 width값 딱 200. */
  box-sizing: border-box;
}
```

#### display

```html
🤗 span은 원래 콘텐츠 영역만큼 차지하나, block을 적용하면 div처럼 줄바꿈되어
차지한다.
<span class="box d-block">display:block</span>
<span class="box d-block">display:block</span>
🤗 div는 원래 줄바꿈되어 화면만큼 차지하나, inline을 적용하면 span처럼 콘텐츠
영역만큼 차지한다.
<div class="box d-inline">display:inline</div>
<div class="box d-inline">display:inline</div>
```

```css
.d-block {
  display: block;
}

.d-inline {
  display: inline;
}
/* inline-block으로 바꾸면 inline처럼 콘텐츠 영역만큼 차지하면서도 width, height 값을 적용할 수 있다. but 요즘은 사용하지 X (대신 flex 사용) */
```

#### position : 기본값 static

- relative(<i>상대적인</i>) : 원래 자리 기준으로 이동
- absolute(<i>절대적인</i>) : 가장 가까운 부모가 position: relative일 시의 기준 (없을 시 화면)
- fixed(<i>고정된</i>) : 화면(뷰포트) 기준, 스크롤해도 고정
- sticky : 이전까지는 움직이다가, 스크롤하다 지정 위치에 닿으면 고정

```html
<div class="pos-outer">
  <div class="pos-box relative">relative</div>
  <div class="pos-box absolute">relative</div>
  <div class="pos-box fixed">fixed</div>
</div>
  <div class="pos-box sticky">sticky</div>
</div>
```

```css
.pos-outer {
  overflow: auto;
  position: relative; /* 자식의 위치를 정하는 기준점 */
  /* widht값 지정하지 않아 화면 비율인 100%로 출력된다. */
  height: 250px;
  border: 1px solid;
  backgrouond: #f6f6f6;
}

.pos-box {
  width: 100px;
  height: 60px;
  color: #fff;
}

.relative {
  background-color: navy;
  position: relative;
  /* relative를 적용한 후 음수값 또는 양수값으로 자리를 이동시킬 수 있다. */
  top: 10px;
  left: 10px;
  z-index: 1;
}

.absolute {
  background-color: lightgreen;
  position: absolute;
  /* z-index : 0에서 시작. position이 걸려있는 요소 중, 겹치는 요소가 있을 시 숫자가 클수록 상위에 노출된다. */
  z-index: 1;
  top: 20px;
  left: 20px;
}

.fixed {
  background-color: crimson;
  position: fixed;
  bottom: 10px;
  right: 10px;
}

.sticky {
  background-color: orange;
  position: sticky;
}
```

#### overflow 박스보다 내용이 넘치는 경우

hidden은 차지하는 영역까지만 표시하고 그 이후는 크롭. overflow는 자동으로 스크롤 생성.

```html
<div class="box of-hidden">hidden : lorem (lorem은 태그 사용)</div>
<div class="box of-auto">auto : lorem (lorem은 태그 사용</div>
```

```css
.of-hidden {
  /* 예시 : 긴 유튜브 제목을 유튜브 홈에서 봤을 때. */
  overflow: hidden;
  text-overflow: ellipsis; /* 말줄임표(···) 표시 */
}

.of-auto {
  overflow: auto;
}
```

#### visibility:hidden vs display:none

```html
<div class="box hidden">보통 박스</div>
ㄴ visibility : hidden -> 자리는 남는다.
<div class="box none">보통 박스</div>
ㄴ display : none -> 자리도 사라진다.
```

```css
.hidden {
  visibility: hidden;
}

.none {
  display: none;
}
```
