## 스크롤 이벤트

```html
<div id="wheel">휠을 움직여보세요!</div>
<div id="scroll"></div>
```

```js
✨ wheel 휠 위아래로 이동
const wheel = document.querySelector("#wheel");
document.addEventListener("wheel", (e) => {
  if (e.deltaY < 0) {
    wheel.textContent = "휠을 위로 올림!"; // console에 음수값 출력
  } else {
    wheel.textContent = "휠을 아래로 내림!"; // console에 양수값 출력
  }
});

✨ scroll 화면에 스크롤이 생겼을 때의 위치 추적
const scroll = document.querySelector("#scroll");
document.addEventListener("scroll", () => {
  const scrollHeight = document.documentElement.scrollHeight; // 전체 높이
  const innerHeight = window.innerHeight; // 현재 화면에 보이는 높이
  const scrollY = window.scrollY; // 스크롤 위치
  // scrollY + innerHeight === scrollHeight
  const totalHeight = scrollHeight - innerHeight;
  const width = (scrollY / totalHeight) * 100;
  scroll.style.width = `${width}%`;
});
```

## 키보드 이벤트

```html
<input type="text" id="key" />
<p id="keyResult"></p>
<div class="moveBox"></div>
```

```js
const key = document.querySelector("#key");
const keyResult = document.querySelector("#keyResult");
key.addEventListener("keydown", (e) => {
  // keydown 눌렀을 때, keypress 눌러진 때, keyup 누른 걸 뗄 때
  keyResult.textContent = e.key; // 무슨 키인지 출력
});

const move = document.querySelector(".moveBox");
let y = 0;
let x = 0;
document.addEventListener("keyup", (e) => {
  if (e.key === "ArrowUp") {
    y -= 50;
  } else if (e.key === "ArrowDown") {
    y += 50;
  } else if (e.key === "ArrowLeft") {
    x -= 50;
  } else if (e.key === "ArrowRight") {
    x += 50;
  }
  move.style.top = `${y}px`;
  move.style.left = `${x}px`;
});
```

## 폼 이벤트

```html
<form action="" id="form">
  <input type="text" id="input" />
  <p id="inputResult"></p>
  <select name="" id="select">
    <option value="사과">사과</option>
    <option value="블루베리">블루베리</option>
  </select>
  <p id="selectResult"></p>
  <button type="submit">제출</button>
</form>
```

```js
const form = document.querySelector("#form");
const input = document.querySelector("#input");
const inputResult = document.querySelector("#inputResult");
form.addEventListener("submit", (e) => {
  if (input.value === "") {
    e.preventDefault();
  }
});
input.addEventListener("input", () => {
  // input이 입력될 때마다 모두 출력.
  inputResult.textContent = input.value;
});
const select = document.querySelector("#select");
const selectResult = document.querySelector("#selectResult");
select.addEventListener("change", (e) => {
  selectResult.textContent = e.target.value;
});
```

## 탭 전환

```html
<div x-data="{tab: 'a'}">
  <button class="tab-btn" :class="{active: tab === 'a'}" @click="tab = 'a'">
    소개
  </button>
  <button class="tab-btn" :class="{active: tab === 'b'}" @click="tab = 'b'">
    예약
  </button>
  <div x-show="tab === 'a'">소개 내용입니다.</div>
  <div x-show="tab === 'b'">예약할 수 있는 곳입니다.</div>
</div>
```
