## array (배열)

### 배열

하나의 변수에 여러 값을 저장하는 자료형.<br>대괄호[] 안에 데이터 값을 입력한다.

```html
<script>
  const arr = [1, 2, 3, 4, 5];
  console.log(arr);
  console.log(typeof arr); // object(객체) -> 이후에 나욜 내용
  console.log(Array.isArray(arr)); // Array.isArray(변수명) -> 배열일 경우 true, 배열이 아닐 경우 false
  console.log(arr[0]); // 배열 인덱스는 0부터 시작하므로, 처음 값을 불러오려면 arr[배열순서]를 입력한다.
  console.log(arr.length); // 현재 배열의 길이
  // 배열의 마지막 값
  console.log(arr[arr.length - 1]);
</script>
```

### 배열 요소 추가

```html
<script>
  arr.push(6); // 변수명.push(추가할 값) -> 맨 뒤에 해당 값을 추가.
  arr.unshift(0); // 변수명.unshift(추가할 값) -> 맨 앞에 해당 값을 추가.
  arr.splice(3, 0, 9, 2); // 변수명.splice -> (몇 번째 인덱스에, 삭제할 개수, 추가할 값···)
  console.log(arr); // [0, 1, 2, 9, 2, 3, 4, 5, 6]
</script>
```

### 배열 요소 삭제

```html
<script>
  arr.pop(); // 변수명.pop() 사용 시, 맨 뒤의 값 1개를 삭제.
  arr.shift(); // 변수명.shift() 사용 시, 맨 앞의 값 1개를 삭제.
  arr.splice(2, 1); // 변수명.splice(몇 번째 인덱스에, 삭제할 개수)
  console.log(arr);
</script>
```

### 배열 요소 수정

```html
<script>
  // 인덱스 1의 값을 100으로 수정? 변수명.splice로 기존 값을 삭제하면서 새 값을 추가한다.
  arr.splice(1, 1, 100);
  console.log(arr);
  // 값이 4인 것을 777로 수정?
  // indexOf(값) -> 해당 값의 인덱스를 알려준다. O가 대문자임에 주의!
  console.log(arr.indexOf(4));
  arr.splice(arr.indexOf(4), 1, 777);
  console.log(arr);
  // 또는, const index = arr.indexof(4) 를 해서 arr.splice(index, 1, 777);로 하면 정리가 잘 된다.
  const index = arr.indexOf(2);
  // 변수명[변수명 (값으로 인덱스를 찾은 변수)] 을 선언한 후 참조하여 값을 바꿀 수도 있다.
  arr[index] = 999;
  console.log(arr);
</script>
```

### 배열 정렬

```html
<script>
  arr.sort(); // 문자 가나다순 정렬
  arr.sort((a, b) => a - b); // 숫자 오름차순 정렬
  arr.reverse(); // 마지막으로 배열된 순서의 역순으로 정렬
  console.log(arr);
</script>
```

### 문자열 - 배열

```html
<script>
  const str = "Hello, JavaScript!";
  // split(구분자) : 문자열 to 배열
  // 구분자 생략 시 문자 자체를 하나의 배열로, "" 지정 시 문자 하나하나를 배열로, "" 사이에 문자 입력 시 해당 문자를 제하고 배열로 한다.
  const strToArr = str.split("");
  console.log(strToArr);
  // join(구분자) : 배열 to 문자열
  // "" 지정 시 통째로 문자열로, "" 안에 문자열 넣을 경우 문자와 문자 사이에 해당 문자
  const arrToStr = strToArr.join("&");
  console.log(arrToStr);
</script>
```
