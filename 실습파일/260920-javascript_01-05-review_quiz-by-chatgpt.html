수업에서 나온 개념을 하나씩 직접 써보는 용도입니다. 정답은 넣지 않았습니다. 먼저 직접 작성하고, 막히면 힌트만 열어보세요.

01. 변수와 연산자

1. var / let / const

var, let, const를 각각 한 번씩 사용해 변수를 선언하세요. 그중 let으로 만든 값만 한 번 바꿔 다시 출력하세요.

힌트

수업에서는 var는 예전 문법, let은 값 변경 가능, const는 값 변경 불가로 다뤘습니다.

2. string / number / boolean + typeof

문자열, 숫자, Boolean 값을 하나씩 변수에 저장하고 typeof로 각각의 자료형을 출력하세요.

3. undefined / null

4. 템플릿 리터럴

힌트

5. 사칙연산 / 나머지

6. parseInt

7. Number / String / parseFloat

문자열 "100"을 숫자로, 숫자 100을 문자열로, 문자열 "3.14"를 실수로 변환하세요. 각각 typeof도 확인하세요.

8. NaN

9. Boolean 변환

"Hello", 빈 문자열 "", 0, 1을 각각 Boolean()으로 변환해 결과를 확인하세요.

10. == / === / != / !==

const a = 100;, const b = "100";을 준비하고 네 비교 연산자를 각각 사용해 결과를 출력하세요.

11. < > <= >=

100과 200을 사용해 네 가지 크기 비교 연산자를 한 번씩 사용하세요.

12. && / ||

x = 10, y = 20일 때 두 조건이 모두 참인 식을 &&로, 둘 중 하나만 참이어도 되는 식을 ||로 작성하세요.

13. 단축 평가

"" && 12345, null || "JS", 1 || "JS"를 각각 출력하고 결과를 비교하세요.
